What this is: the same frozen 532-neuron v3 recurrent-controller weights and motor-readout equations are evaluated directly in your browser. The controller port was numerically checked against the Python checkpoint on a deterministic test sequence.

Important: these browser trials are qualitative post-freeze demonstrations. Browser random-number generation is not NumPy's benchmark RNG, so a browser seed is not a Python benchmark seed. New runs do not change the reported 70/100 held-out result.

Model scope

This is a connectome-constrained navigation controller, not a complete fly brain or fully biophysical simulation. Body heading is supplied externally; bilateral odor→FB5AB and parts of PFN wind tuning are modeling conventions.
