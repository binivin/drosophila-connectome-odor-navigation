# Figure artifacts

This directory contains the final public vector figures used to summarize the frozen project state.

## Files

| File | Description |
|---|---|
| `final_results_summary.svg` | Final held-out v3/v6 results, paired outcomes, and project scope |
| `final_runtime_architecture.svg` | Checkpoint-driven closed-loop runtime architecture |

The original research notebook also produced additional exploratory and diagnostic figures, including connectome-family perturbation, rewiring controls, PFL laterality, plume diagnostics, and trajectory plots. Those figures are not required for the minimal public runtime, while their scientific conclusions are retained in `docs/final_research_summary.md`.

The SVG format is kept in GitHub because it is lightweight, versionable, and renders directly in the repository README.
